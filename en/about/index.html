What this station is for

This station classifies music by how it sounds. It answers three questions: what does it feel like, where does it come from, and what should I start with if I want to hear more of it.

What it will contain

  • Broad categories — classical and Romantic, jazz, rock and pop, electronic, world music.
  • Sub-styles — the branches under each, explaining exactly how they differ from the parent: rhythm, timbre, line-up, setting.
  • A family tree — who influenced whom, and when the branches split. This is the station's main visualisation.
  • Representative tracks — every style gets examples that really exist in the library, so you can listen while you read.
  • Chinese traditions — not here; they all live on the Chinese music station. This station keeps only a single doorway to it.

What each entry looks like

  • It opens with how it sounds — not "it is lyrical" but what you actually hear: which rhythmic patterns, which timbres, which ways of playing, which forms.
  • Then where it came from: which music it grew out of, and in what setting it became popular.
  • Finally the boundary: how it differs from the style it is most often confused with.

How to read it

1. Start from the broad categories — get the main divisions clear, then go down. 2. Read the family tree — one map explains "who came from whom" faster than ten entries. 3. Compare across — the same melody handled in different styles is the clearest test.

Where it stands today

Entries are being added over time, starting with the skeleton of the broad categories and then filling in sub-styles one by one — so that every entry, when it arrives, already has a place on the map instead of hanging on its own. :::
